# IEEE-style draft

`paper.tex` is an IEEE-conference-style draft describing the project as it
exists: the benchmark, evaluation design, false-positive audit and measurement
findings. Every number in it is taken from the committed CSVs/JSON in `data/`
and `dashboard/`; no result is overstated and no review outcome is claimed.
Author placeholders for teammates must be filled in before any submission.

Compile with pdflatex and the IEEEtran class (from CTAN or TeX Live
`texlive-publishers`); the only other packages used are `url` and `amsmath`.
The compiled PDF is shared separately, not tracked here.
