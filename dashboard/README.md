# Dashboard exports

Generated by `python src/pipeline.py`. Join keys: `polity`, `time_t`.
`fp_cases.csv` uses `century`; the Power BI query normalizes the compound key.

- predictions.csv: one row per labeled observation; model_score is seed-0 grouped
  logistic OOF output, uncalibrated. Terr/next_Terr are label provenance, never
  predictive inputs.
- shap_long.csv: actual linear SHAP for that held-out fold model. value is the
  imputed/scaled model input, including missing indicators; shap_value/base_value
  are log-odds. Sum SHAP plus base reconstructs the matching OOF score logit.
- shap_groups.csv: summed SHAP by explicitly named feature family. There are no
  fabricated military/succession measures in this feature set.
- fp_cases.csv: fixed model_score >=0.70 and observed outcome not decline.
  All unreviewed cases are pending, not genuine-survival findings.
- fold_metrics.csv, metrics_summary.csv: per-fold metrics and mean/std/count.
- run_metadata.json: source and evaluation settings.

The older shap_long.csv content was coefficient contributions from a full-data
fit; it is replaced with true OOF SHAP, not merely renamed. Dashboard scores and
explanations now refer to the same model fit. Do not use these scores to assess
modern countries or infer causes of historical change.
