## Recommendation

The broad pitch "use ML/Seshat to predict civilizational collapse" is not a
supported novelty claim. The most defensible possible contribution is a
**measurement-aware historical forecasting benchmark**: trace every row's identity,
geometry eligibility, feature time support and exclusion; quantify label sensitivity;
compare group/time-aware baselines; publish negative results as honestly as positive
ones. That contribution remains a candidate until a focused review and expert
feedback establish whether its specific design adds useful new knowledge.

This project currently has a selected continuing-ID area endpoint, not a complete
collapse cohort. It has not established that governance features can predict the
endpoint, nor that the area-only model improves robustly out of period/group.
Existing related work is a reason to tighten the question, not to chase a favorable
score. A revised hypothesis must be set before new confirmatory data are evaluated.

## Important comparison cautions

The PNAS paper reports rising early-life termination hazard across its selected
cohorts; the public PsychohistoryML repository claims decreasing hazard in another
sample/model. These are different endpoints, samples, periodizations and models.
Do not average them, treat the repository as equivalent evidence, or pick the sign
that supports this project. Such disagreement motivates replication, explicit
inclusion rules and source review. This project did not audit that repository's
notebooks or reproduce its claimed results.

AUC, macro-F1, hazard shape, spatial R-squared and overall area-density agreement
measure different things. Prior numbers are not scores this project should beat.
Retrodiction with historically informed mechanisms is not equivalent to an
untouched out-of-period forecast.
